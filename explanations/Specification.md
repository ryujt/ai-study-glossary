# 명세 (Specification)

명세는 무엇을 만들지와 어떤 조건을 만족해야 하는지를 정리한 문서다.

## 개발할 때

비밀번호 재설정 기능이라면 요청 화면, 만료된 링크 처리, 실패 메시지, 기존 로그인과의 관계를 적는다. AI가 빠진 정책을 임의로 정하기 전에 합의할 기준을 만든다.

## 기억할 점

처음부터 긴 문서를 쓸 필요는 없다. 변경의 목적과 범위, 예외, 확인 방법이 분명하면 작은 수정에도 쓸 수 있다. 명세 기반 개발(spec-driven development)은 이런 명세를 기준으로 구현과 검증을 진행하는 접근이다.

근거: [Claude Code: 개발 작업 가이드](https://code.claude.com/docs/en/best-practices).
