# 에이전트 루프 (Agent Loop)

에이전트 루프는 에이전트가 다음 행동을 정하고, 도구를 실행하고, 결과를 읽는 과정을 반복하는 구조다.

## 개발할 때

버그 수정에서는 “관련 코드 읽기 → 수정 → 테스트 실행 → 실패 원인 확인 → 다시 수정”으로 이어진다. 매번 사람이 다음 명령을 입력하지 않아도 도구 결과를 근거로 진행할 수 있다.

## 기억할 점

같은 오류를 반복하면 저절로 해결된다고 기대하지 않는다. 실행 횟수와 시간 한도를 두고, 진전이 없거나 요구가 모호하면 멈춰 사람이 원인을 확인하게 한다.

근거: [Anthropic: 에이전트와 워크플로](https://www.anthropic.com/research/building-effective-agents).
