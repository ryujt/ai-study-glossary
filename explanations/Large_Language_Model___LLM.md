# 대규모 언어 모델 (LLM)

대규모 언어 모델(large language model)은 많은 텍스트에서 패턴을 학습해 질문에 답하거나 코드를 생성하는 모델이다.

## 개발할 때

오류 로그를 주고 원인 후보를 묻거나, 함수의 역할을 설명해 달라고 할 수 있다. 모델에 파일 읽기나 명령 실행 도구를 붙이면 실제 개발 작업을 수행하는 에이전트로 활용할 수 있다.

## 기억할 점

유창한 답변이 정확성을 보장하지는 않는다. 최신 라이브러리 사용법과 프로젝트 내부 사정은 관련 문서와 코드를 제공하고 실행 결과로 확인한다.
