# Underfitting (과소적합)

> **과소적합은 모델이 너무 단순하거나 덜 배워서, 학습 데이터의 기본 규칙조차 잡아내지 못하는 상태다.**

## 곡선 데이터에 직선을 억지로 그은 것과 같다

분명히 곡선을 그리는 데이터에 자만 대고 직선을 그으면, 학습 데이터든 새 데이터든 어디에도 잘 안 맞는다. **과소적합된 모델이 바로 이 직선이다.** 표현력이 부족해 데이터에 깔린 규칙을 담아내지 못한다. [과적합](Overfitting.md)이 "너무 많이 외운" 상태라면, 과소적합은 "아직 못 배운" 상태다.

가장 중요한 신호는 **학습 데이터에서부터 성능이 낮다**는 점이다. 과적합은 학습은 잘하지만 새 데이터에서 무너지는 반면, 과소적합은 학습 데이터조차 제대로 못 맞힌다. 그래서 학습 오차와 검증 오차가 **둘 다 높고 서로 비슷하다**.

> ⚠️ **흔한 오해 — "과소적합도 데이터의 잡음까지 외우다 생긴다."**
>
> 잡음까지 외우는 것은 정반대인 과적합의 특징이다. 과소적합은 모델이 잡음은커녕 **핵심 신호조차 못 배운** 상태다. 원인은 과한 학습이 아니라 부족한 표현력이나 부족한 학습이다.

## 모델이 너무 단순하거나 학습이 모자랄 때 생긴다

과소적합의 원인은 대체로 세 갈래다.

- **모델이 데이터에 비해 지나치게 단순할 때** — 파라미터·층이 부족해 복잡한 관계를 담을 그릇이 안 된다. 비선형 데이터에 선형 모델을 쓰는 경우가 전형적이다.
- **학습이 충분히 진행되지 않았을 때** — [에포크](Epoch.md)가 너무 적거나 [학습률](Learning_Rate_Scheduler.md)이 안 맞아 아직 수렴 전이다.
- **정규화가 지나칠 때** — [정규화](Regularization.md)를 너무 세게 걸면 모델이 필요한 복잡도마저 못 갖춘다.

## 편향-분산에서 "높은 편향" 쪽이다

과소적합과 과적합은 편향-분산 트레이드오프의 양 끝이다.

| 구분 | 과소적합 | 과적합 |
|------|---------|--------|
| 모델 복잡도 | 너무 낮음 | 너무 높음 |
| 학습 오차 | 높음 | 낮음 |
| 검증 오차 | 높음 | 높음 |
| 두 오차의 격차 | 작음 (둘 다 나쁨) | 큼 |
| 성격 | 높은 [편향](Bias.md) | 높은 분산 |

해법은 과적합과 반대 방향이다. **모델을 더 복잡하게** 만들거나(층·파라미터 추가), 유용한 [특성](Feature_Engineering.md)을 더하거나, 더 오래 학습하거나, 과한 정규화를 완화한다. 학습을 계속했더니 검증 오차가 오르기 시작하면 그때가 과적합으로 넘어가는 지점이니, 그 직전 균형점을 노린다.

## 정리하면

- 과소적합은 모델이 **학습 데이터의 규칙조차 못 배운** 상태다.
- 증상은 **학습 오차·검증 오차가 둘 다 높음**이다.
- 원인은 지나친 단순함, 부족한 학습, 과한 정규화다.
- 편향-분산에서 **높은 편향** 쪽이며, 해법은 모델을 키우고 특성을 늘리는 것이다.
