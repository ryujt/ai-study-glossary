# 체크포인트 (Checkpoint)

체크포인트는 작업이 잘못됐을 때 돌아갈 수 있도록 저장해 둔 상태다.

## 개발할 때

큰 수정을 맡기기 전에 현재 변경을 확인하고 Git 커밋 등으로 기준점을 남긴다. 코딩 도구가 제공하는 되돌리기 기능도 실험한 수정을 복구하는 데 쓸 수 있다.

## 기억할 점

도구의 체크포인트가 모든 변경을 기록하지는 않는다. 터미널로 바꾼 파일, 데이터베이스 수정, 외부 서비스의 작업까지 되돌릴 수 있다고 가정하지 않는다. 복구 범위를 확인하고 Git 기록도 관리한다.

근거: [Claude Code: 체크포인트의 범위](https://code.claude.com/docs/en/checkpointing).
