# Machine Learning (머신러닝)

> **머신러닝은 규칙을 사람이 직접 짜 넣는 대신, 데이터에서 규칙을 스스로 찾아내게 하는 방법이다.**

## 규칙을 짜는 대신 예시를 보여준다

스팸 메일을 걸러낸다고 해보자. 전통적인 방식이라면 "제목에 '무료'가 있으면 스팸", "링크가 5개 넘으면 스팸" 같은 규칙을 사람이 하나하나 손으로 적어야 한다. 스팸의 수법이 바뀔 때마다 규칙도 다시 짜야 한다.

머신러닝은 접근이 다르다. **스팸 메일 수천 통과 정상 메일 수천 통을 보여주고, 둘을 가르는 규칙을 기계가 직접 찾게 한다.** 아이에게 고양이 사진을 잔뜩 보여주면 "고양이란 이런 것"을 스스로 감 잡는 것과 같다. 정의를 말로 못 해도 새 사진에서 고양이를 알아본다.

이때 기계가 찾아낸 규칙 덩어리를 **모델(model)**이라 하고, 데이터를 보여주며 모델을 다듬는 과정을 **학습(training)**이라 한다.

## 무엇을 보여주느냐에 따라 세 갈래로 나뉜다

머신러닝은 데이터에 정답(레이블)이 붙어 있느냐, 어떻게 배우느냐에 따라 크게 셋으로 갈린다.

| 갈래 | 데이터 | 하는 일 | 예 |
|------|--------|---------|-----|
| [지도학습](Supervised_Learning.md) | 입력 + 정답 | 정답을 맞히는 규칙을 배운다 | 사진→고양이, 메일→스팸 |
| [비지도학습](Unsupervised_Learning.md) | 입력만 | 데이터 속 숨은 구조를 찾는다 | 고객을 비슷한 무리로 [군집화](Clustering.md) |
| [강화학습](Reinforcement_Learning.md) | 보상 신호 | 시행착오로 좋은 행동을 배운다 | 게임 플레이, 로봇 제어 |

## 학습은 데이터를 흘려보내며 모델을 다듬는 순환이다

```mermaid
graph LR
  A["데이터 수집<br/>+ 전처리"] --> B["모델 학습<br/>패턴 파악"]
  B --> C["평가<br/>처음 보는 데이터로 검증"]
  C -->|"성능 부족"| B
  C -->|"충분"| D["배포<br/>실제 예측"]
```

핵심은 **학습에 쓴 데이터가 아니라 처음 보는 데이터에서의 성능**이다. 학습 데이터만 잘 맞히는 건 의미가 없다. 그래서 데이터를 [학습/테스트로 나눠](TrainTest_Split.md) 한 번도 보지 않은 데이터로 성능을 재야 한다.

## 흔한 오해

> ⚠️ **흔한 오해 — "머신러닝은 딥러닝이랑 같은 말이다."**
>
> [딥러닝](Deep_Learning.md)은 머신러닝의 한 갈래일 뿐이다. 여러 층의 [신경망](Neural_Network.md)을 쓰는 방식이 딥러닝이고, [의사결정 트리](Decision_Tree.md), [SVM](Support_Vector_Machine___SVM.md), [K-means](Kmeans_Algorithm.md)처럼 신경망을 안 쓰는 머신러닝도 아주 많다.

> ⚠️ **흔한 오해 — "데이터만 많으면 잘 된다."**
>
> 양보다 질이다. 정답이 잘못 붙은 데이터, 편향된 데이터, [누수](Data_Leakage.md)가 있는 데이터로는 아무리 많아도 좋은 모델이 안 나온다. 그래서 [데이터 전처리](Data_Preprocessing.md)와 [특성 공학](Feature_Engineering.md)에 시간이 많이 든다.

## 정리하면

- 머신러닝은 **규칙을 손으로 짜는 대신 데이터에서 규칙을 학습**하는 방법이다.
- 데이터에 정답이 붙었는지에 따라 지도·비지도·강화학습으로 나뉜다.
- 성능은 학습 데이터가 아니라 **처음 보는 데이터**에서 재야 한다.
- 딥러닝은 머신러닝의 한 갈래이지 전부가 아니다.
