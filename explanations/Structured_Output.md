# 구조화된 출력 (Structured Output)

구조화된 출력은 결과를 프로그램이 읽을 수 있도록 정해진 데이터 형식과 구조로 받는 기능이다.

## 개발할 때

AI가 찾은 코드 문제를 파일명, 위치, 설명 필드가 있는 JSON으로 받으면 후속 검사 도구에 전달하기 쉽다. 출력 구조를 정의하는 규칙을 스키마(schema)라고 한다.

## 기억할 점

“JSON으로 답해 줘”라는 요청과 스키마를 강제하는 기능은 구분한다. 지원 범위는 제품마다 다르며, 구조가 맞아도 파일 경로나 설명이 틀릴 수 있으므로 값의 의미도 검사한다.

근거: [Google: 구조화된 출력](https://ai.google.dev/gemini-api/docs/structured-output).
