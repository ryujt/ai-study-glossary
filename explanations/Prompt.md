# 프롬프트 (Prompt)

프롬프트는 AI에게 할 일과 필요한 조건을 전달하는 입력이다.

## 개발할 때

“로그인 고쳐 줘”보다 “세션이 만료된 뒤 빈 화면이 나온다. 재현 절차와 관련 파일은 다음과 같다. 로그인 화면으로 이동하게 고치고 기존 로그인 테스트를 실행해 줘”가 작업 범위를 파악하기 쉽다.

## 기억할 점

좋은 요청에는 목표, 관련 자료, 지켜야 할 제약, 확인 방법이 들어간다. 민감한 값은 지우고, 아직 모르는 조건은 AI가 추측하기 전에 확인하게 한다.
