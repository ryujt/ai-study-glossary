# Softmax (소프트맥스 함수)

> **소프트맥스는 여러 개의 실수 점수를 모두 더하면 1이 되는 확률 분포로 바꾸는 함수다.** 다중 클래스 분류의 출력층에서 "어느 클래스일 확률이 몇 %인지"를 만들어 낸다.

## 득표수를 득표율로 환산하는 것과 같다

선거에서 후보마다 받은 표(로짓, logit)를 그대로 비교하긴 어렵다. 그래서 전체 표로 나눠 백분율로 바꾼다. **소프트맥스가 하는 일이 바로 이 환산이다.** 다만 단순히 나누기만 하는 게 아니라, 먼저 지수 함수 `exp`를 씌운 뒤 나눈다.

```
softmax(z_i) = exp(z_i) / Σ_j exp(z_j)
```

- `z_i`는 클래스 `i`의 점수(로짓), 분모는 모든 클래스 지수값의 합이다.
- `exp`를 씌우므로 음수 점수도 **양수**가 되고, 큰 점수와 작은 점수의 차이가 **더 벌어진다**. 즉 앞선 후보에게 더 몰아준다.
- 결과는 모두 0~1 사이이며 **합이 정확히 1**인 확률 분포다.

예를 들어 로짓이 `[2.0, 1.0, 0.1]`이면 소프트맥스는 대략 `[0.66, 0.24, 0.10]`이 된다. 가장 큰 값이 확률의 대부분을 가져가지만, 나머지도 완전히 0은 아니다.

## 실전에서는 지수 계산을 안전하게 다뤄야 한다

`exp`는 입력이 조금만 커도 값이 폭발한다. `exp(1000)`은 오버플로로 무한대가 된다. 그래서 실제 구현은 **가장 큰 로짓을 모든 값에서 빼고** 계산한다. 결과는 수학적으로 동일하지만 수치적으로 안전하다.

```
softmax(z_i) = exp(z_i - max(z)) / Σ_j exp(z_j - max(z))
```

소프트맥스는 거의 항상 [교차 엔트로피](CrossEntropy.md) 손실과 짝을 이룬다. 이 조합은 미분이 `예측 확률 - 정답`이라는 깔끔한 형태로 정리돼 학습이 안정적이다.

## 흔한 오해

> ⚠️ **흔한 오해 — "소프트맥스 확률이 곧 모델의 신뢰도다."**
>
> 출력이 합 1인 확률 분포라서 0.99가 나오면 확신하는 것처럼 보이지만, 신경망은 틀린 답에도 태연히 0.99를 주는 **과신(overconfidence)** 경향이 있다. 소프트맥스 값은 클래스 간 상대 순위일 뿐, 잘 보정된 확률이라는 보장은 없다.

> 💡 **참고 — 소프트맥스 vs 시그모이드.**
> 서로 배타적인 클래스 중 **하나**를 고를 때(개 아니면 고양이 아니면 새) 소프트맥스를 쓴다. 여러 레이블이 **동시에** 참일 수 있을 때(사진에 개도 있고 사람도 있음)는 각 출력에 [시그모이드](Sigmoid.md)를 따로 쓴다. 클래스가 둘뿐이면 소프트맥스는 시그모이드와 같아진다.

## 정리하면

- 소프트맥스는 로짓을 `exp`로 키운 뒤 정규화해 **합이 1인 확률 분포**로 만든다.
- `exp` 덕분에 큰 점수에 더 몰아주는 "승자 강조" 효과가 있다.
- 오버플로를 막으려면 **최댓값을 빼고** 계산한다.
- 다중 클래스 분류 출력층에서 [교차 엔트로피](CrossEntropy.md)와 짝으로 쓴다.
