# 프롬프트 캐싱 (Prompt Caching)

프롬프트 캐싱은 반복되는 입력의 처리 결과 일부를 재사용해 비용이나 응답 시간을 줄이는 기능이다.

## 개발할 때

같은 프로젝트 지침과 도구 설명을 여러 요청에서 보낼 때 활용될 수 있다. 입력 내용과 배치가 바뀌면 캐시를 재사용하지 못할 수 있다.

## 기억할 점

이전 답변을 그대로 돌려주는 응답 캐시나 장기 메모리와는 다르다. 지원 여부, 일치 조건, 유지 시간, 요금은 제품마다 다르므로 사용량 화면이나 로그에서 실제 적용 여부를 확인한다.

근거: [Claude Code: 프롬프트 캐싱](https://code.claude.com/docs/en/prompt-caching).
