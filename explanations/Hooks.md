# 훅 (Hooks)

훅은 도구 실행 전후나 작업 종료 같은 정해진 시점에 자동으로 실행되는 처리다.

## 개발할 때

파일을 수정한 뒤 코드 모양을 맞추는 포맷터를 실행하거나, 종료 시 검사 스크립트를 실행하도록 연결한다. 매번 AI에게 같은 검사를 부탁하는 수고를 줄일 수 있다.

## 기억할 점

훅이 통과했다고 전체 요구사항이 충족되는 것은 아니다. 실행 시점과 차단 기능은 제품마다 다르며, 종료를 막는 훅은 반복 실행과 실패 처리도 고려한다.
