# Batch Normalization (배치 정규화)

> **배치 정규화는 각 층으로 들어가는 값을 미니배치 단위로 평균 0·분산 1에 맞춰 다시 정렬함으로써, 깊은 신경망의 학습을 빠르고 안정적으로 만드는 기법이다.**

## 층마다 눈금이 제멋대로인 저울을 매번 0점 조정하는 것과 같다

학습이 진행되면 앞쪽 층의 가중치가 바뀌고, 그러면 다음 층으로 들어오는 값의 분포도 매번 출렁인다. 뒤쪽 층은 계속 흔들리는 입력에 맞춰 다시 적응해야 해서 학습이 더디다. **배치 정규화는 각 층 입구에 "0점 조정된 저울"을 두는 것과 같다.** 들어오는 값을 그때그때 평균 0, 분산 1로 다시 맞춰 주니, 뒤쪽 층은 안정된 눈금 위에서 학습할 수 있다.

## 정규화한 뒤, 다시 자유를 돌려준다

핵심은 두 걸음이다. 먼저 **정규화**, 그다음 **되돌리기**.

```
정규화:   x̂ = (x - μ_B) / √(σ²_B + ε)
스케일·시프트:  y = γ · x̂ + β
```

- `μ_B`, `σ²_B` — 미니배치 안에서 계산한 평균과 분산.
- `ε` — 분모가 0이 되는 걸 막는 아주 작은 상수.
- `γ`, `β` — **학습되는 파라미터**. 무조건 평균 0·분산 1로 고정하면 표현력이 줄 수 있으니, 필요하면 모델이 스케일과 위치를 도로 조정하도록 자유를 준다.

> 💡 **참고 — 학습할 때와 추론할 때가 다르다**
>
> 학습 중에는 매 미니배치의 통계로 정규화한다. 하지만 추론에서는 배치가 없거나 한 개일 수 있으므로, 학습 동안 이동평균으로 모아 둔 전체 평균·분산을 대신 쓴다. 이 두 모드를 헷갈리면 추론 성능이 무너진다.

## 흔한 오해

> ⚠️ **흔한 오해 — "배치 정규화는 입력 데이터를 한 번 정규화하는 전처리다."**
>
> 데이터 전처리와 다르다. 배치 정규화는 **신경망 내부의 층과 층 사이에 들어가는 연산**이고, 학습되는 파라미터(`γ`, `β`)를 가지며, 매 미니배치마다 동작한다. 데이터를 학습 전에 한 번 스케일링하는 것과는 층위가 다르다.

## 무엇을 얻나

| 효과 | 이유 |
|------|------|
| 학습 속도 향상 | 분포가 안정돼 더 큰 학습률을 써도 발산하지 않는다 |
| 초기값 민감도 완화 | 층 입력이 매번 재정렬되어 초기 가중치 선택 부담이 준다 |
| 약한 정규화 효과 | 미니배치마다 통계가 조금씩 달라 잡음처럼 작용, 과적합을 살짝 눌러 준다 |

## 정리하면

- 배치 정규화는 층 입력을 **미니배치 단위로 평균 0·분산 1**로 재정렬한다.
- 정규화 뒤 학습 가능한 `γ`, `β`로 스케일과 위치를 되돌려 표현력을 지킨다.
- 학습 시엔 배치 통계, 추론 시엔 이동평균 통계를 쓴다.
- 학습 가속·안정화가 주 효과이고, 약한 과적합 억제는 덤이다.
