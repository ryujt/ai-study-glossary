# Ensemble Methods (앙상블 기법)

> **앙상블 기법은 여러 개의 모델을 묶어 한 표씩 모아 판단함으로써, 혼자보다 더 정확하고 안정적인 예측을 만드는 방법이다.**

## 전문가 한 명보다 위원회의 다수결이 낫다

어려운 진단을 앞두고 의사 한 명에게만 맡기는 것과, 서로 배경이 다른 의사 여러 명의 의견을 모아 결정하는 것 중 어느 쪽이 안심되는가. 한 명이 실수해도 나머지가 바로잡아 준다는 점에서 위원회가 대개 더 든든하다. **앙상블은 바로 이 다수결의 지혜를 모델에 옮긴 것이다.** 개별 모델(약한 학습기, weak learner) 하나하나는 완벽하지 않아도, 서로 다른 실수를 하는 여러 모델을 모으면 실수가 상쇄되어 전체 성능이 올라간다.

핵심 전제는 **모델들이 서로 달라야 한다**는 것이다. 똑같은 판단을 하는 모델 100개를 모아 봐야 한 개와 다를 게 없다. 서로 다른 데이터로, 다른 방식으로 학습해 **오차가 서로 독립적일수록** 앙상블의 이득이 커진다.

## 배깅·부스팅·스태킹, 다양성을 만드는 세 가지 길

| 방식 | 학습 순서 | 다양성을 얻는 법 | 주로 줄이는 것 | 대표 예 |
|------|-----------|------------------|----------------|---------|
| **배깅 (Bagging)** | 병렬 — 서로 독립 | 데이터를 무작위 복원추출해 각 모델을 다른 표본으로 학습 | 분산 (variance) | [랜덤 포레스트](Random_Forest.md) |
| **부스팅 (Boosting)** | 순차 — 앞의 오차를 보완 | 앞 모델이 틀린 샘플에 가중치를 실어 다음 모델이 집중 | 편향 (bias) | [그래디언트 부스팅](Gradient_Boosting.md) |
| **스태킹 (Stacking)** | 2단계 | 서로 다른 종류의 모델 예측을 다시 메타 모델에 입력 | 편향·분산 | 메타 학습기 |

- **배깅**은 "여러 사람이 각자 다른 표본을 보고 판단한 뒤 평균낸다"는 발상이다. 예측을 평균(회귀)하거나 투표(분류)해 튀는 실수를 눌러 분산을 줄인다.
- **부스팅**은 "앞사람이 놓친 문제를 다음 사람이 집중 공략한다"는 발상이다. 약한 학습기를 순차로 쌓아 편향을 줄여 나간다.
- **스태킹**은 종류가 다른 모델들의 예측을 모아 그 위에 또 하나의 모델을 얹어 최종 판단을 배운다.

## 흔한 오해

> ⚠️ **흔한 오해 — "모델을 많이 합칠수록 무조건 좋아진다."**
>
> 모델들이 비슷비슷하게 같은 실수를 한다면 아무리 많이 모아도 나아지지 않는다. 앙상블의 이득은 **다양성**에서 나온다. 또한 모델이 늘수록 학습·예측 비용과 해석의 어려움이 커지므로, 성능 향상과 비용은 늘 저울질해야 한다.

## 정리하면

- 앙상블은 여러 모델을 결합해 **개별 모델의 약점을 서로 메우는** 기법이다.
- 이득의 원천은 모델 간 **다양성** — 서로 다른 실수를 해야 상쇄된다.
- **배깅**은 분산을, **부스팅**은 편향을 주로 줄이고, **스태킹**은 이종 모델을 메타 모델로 묶는다.
- 캐글 등 실전 예측 대회에서 상위권을 휩쓰는 단골 무기다.
