# 하네스 엔지니어링 (Harness Engineering)

하네스 엔지니어링은 에이전트가 일관되게 작업하도록 주변 환경과 실행 규칙을 설계하고 개선하는 일이다.

## 개발할 때

AI가 테스트 명령을 자주 틀린다면 저장소 지침을 고치고, 테스트 실행 방법을 단순하게 만든다. 잘못된 완료 보고가 반복되면 검사 결과를 확인해야 종료하도록 절차를 보강한다.

## 기억할 점

코딩 도구를 사용하는 팀도 지침, 검사 명령, 권한 설정을 개선하며 참여할 수 있다. 규칙을 많이 추가하기보다 실제 실패를 재현하고, 바꾼 뒤 같은 문제가 줄었는지 확인한다.

근거: [LangChain: 에이전트 하네스의 구성](https://www.langchain.com/blog/the-anatomy-of-an-agent-harness).
