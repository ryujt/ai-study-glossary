# Fuzzy Inference (퍼지 추론)

> **퍼지 추론은 "덥다", "약간 빠르다" 같은 애매한 말을 0~1 사이 정도값으로 다뤄, 사람의 언어 규칙으로 판단을 내리는 추론 방식이다.**

## "26도는 더운가?"에 0.7이라고 답한다

참/거짓 둘 중 하나로만 답하는 논리로는 "덥다"를 다루기 곤란하다. 28도는 덥고 27.9도는 안 더운가? 경계가 우습다. [퍼지 집합](Fuzzy_Set.md)은 "이 온도가 '더움'에 **0.7만큼 속한다**"처럼 정도로 표현한다. 퍼지 추론은 이 정도값을 규칙에 태워 결론을 낸다.

에어컨 제어가 전형적인 예다. **"만약 온도가 덥고 습도가 높으면, 바람을 세게 튼다"** 같은 사람 말투 규칙을 그대로 시스템에 넣을 수 있다.

## 세 단계로 흐른다

```mermaid
graph LR
  A["입력값<br/>온도 26 · 습도 70"] -->|"퍼지화"| B["정도값<br/>더움 0.7 · 습함 0.6"]
  B -->|"규칙 평가"| C["규칙 결과<br/>바람 세기 정도"]
  C -->|"비퍼지화"| D["출력값<br/>팬 속도 82퍼센트"]
```

- **퍼지화**: 입력 숫자를 "더움 0.7"처럼 정도값으로 바꾼다.
- **규칙 평가**: `만약 ~라면 ~` 규칙들을 정도에 맞춰 적용한다.
- **비퍼지화(탈퍼지화)**: 규칙 결과를 다시 하나의 실제 출력값(예: 팬 속도 82%)으로 되돌린다.

## 흔한 오해

> ⚠️ **흔한 오해 — "퍼지의 0.7은 확률 0.7이다."**
>
> 다르다. 확률은 "그럴 **가능성**"이고, 퍼지 멤버십은 "그 개념에 **속하는 정도**"다. "이 물이 미지근함에 0.7 속한다"는 불확실이 아니라 정도의 문제다. [확률 추론](Probabilistic_Reasoning.md)과 헷갈리지 말자.

## 정리하면

- 퍼지 추론은 애매한 언어 개념을 **0~1 정도값**으로 다룬다.
- 퍼지화 → 규칙 평가 → 비퍼지화의 세 단계로 흐른다.
- 사람 말투 규칙을 그대로 쓰는 제어 시스템에 강하다.
- 멤버십(정도)은 확률(가능성)과 다르다.
