# RMSprop (RMSprop 옵티마이저)

> **RMSprop은 최근 기울기가 컸던 파라미터의 학습률은 줄이고 작았던 파라미터의 학습률은 키우는, 파라미터마다 보폭을 자동 조절하는 옵티마이저다.**

## 가파른 골짜기에서는 조심조심, 완만한 곳에서는 성큼성큼

험한 산을 내려간다고 하자. 경사가 급한 방향으로는 자칫하면 반대편 벽을 튕겨 오르니 작게 디뎌야 하고, 완만한 방향으로는 크게 성큼 내려가야 빨리 간다. 모든 방향에 같은 보폭을 쓰면 급한 쪽에서는 진동하고 완만한 쪽에서는 굼뜨다. **RMSprop은 방향(파라미터)마다 최근 얼마나 가팔랐는지를 기억해두고, 가팔랐던 방향일수록 보폭을 줄인다.**

기본 [경사 하강법](Gradient_Descent.md)이 모든 파라미터에 하나의 [학습률](Learning_Rate_Scheduler.md)을 똑같이 쓰는 것과 달리, RMSprop은 **적응적 학습률(adaptive learning rate)** 옵티마이저다. 파라미터마다 유효 학습률이 달라진다.

## 제곱 기울기의 이동평균으로 보폭을 나눈다

RMSprop은 각 파라미터의 **최근 기울기 제곱의 지수이동평균**을 유지하고, 그 제곱근으로 학습률을 나눈다.

```
g_t     = ∇L(θ_t)                          # 현재 기울기
E[g²]_t = ρ · E[g²]_{t-1} + (1 - ρ) · g_t²  # 제곱 기울기의 지수이동평균 (ρ 보통 0.9)
θ_{t+1} = θ_t - (η / (√(E[g²]_t) + ε)) · g_t
```

- `ρ` — 감쇠율(decay rate). 과거를 얼마나 오래 기억할지 정한다. 보통 0.9.
- `η` — 기본 학습률.
- `ε` — 0으로 나누는 것을 막는 아주 작은 수(예: 1e-8).

핵심은 분모의 `√(E[g²])`다. 어떤 파라미터의 기울기가 최근 계속 컸다면 이 값이 커져 **유효 학습률이 작아지고**, 반대로 기울기가 줄곧 작았다면 유효 학습률이 커진다. 결과적으로 방향마다 자동으로 보폭이 조절된다.

> ⚠️ **흔한 오해 — "RMSprop은 기울기에 이전 기울기를 더해서 나아간다."**
>
> RMSprop은 기울기를 **더하는** 것이 아니라, 제곱 기울기의 이동평균 제곱근으로 학습률을 **나눈다**. 이전 방향을 관성으로 더하는 것은 Momentum의 아이디어이고, RMSprop이 조절하는 것은 방향이 아니라 방향별 보폭이다.

## Adagrad의 "학습률이 죽는" 문제를 고친 것이다

RMSprop은 Adagrad의 약점을 겨냥해 나왔다. Adagrad는 제곱 기울기를 **처음부터 전부 누적**하기 때문에, 학습이 길어질수록 분모가 한없이 커져 학습률이 0에 수렴해 결국 학습이 멈춰버린다. RMSprop은 누적 대신 **지수이동평균**을 써서 오래된 기울기를 잊는다. 그래서 학습률이 죽지 않고 계속 유효하게 유지된다.

| 옵티마이저 | 방향별 보폭 조절 | 관성(Momentum) |
|-----------|----------------|----------------|
| [SGD](SGD.md) | 없음 (모두 같은 학습률) | 옵션 |
| RMSprop | 있음 (제곱 기울기 이동평균) | 없음 |
| [Adam](Adam.md) | 있음 (RMSprop과 동일) | 있음 |

표에서 보이듯 [Adam](Adam.md)은 사실상 RMSprop의 보폭 조절에 Momentum을 더한 것이다. 그래서 RMSprop을 이해하면 Adam의 절반을 이해한 셈이다.

## 정리하면

- RMSprop은 파라미터마다 **제곱 기울기의 이동평균**을 기억해 유효 학습률을 자동 조절한다.
- 최근 기울기가 컸던 방향은 보폭을 줄이고, 작았던 방향은 보폭을 키운다.
- 제곱 기울기를 전부 누적하는 Adagrad와 달리 이동평균을 써서 **학습률이 죽지 않는다**.
- [Adam](Adam.md)은 RMSprop + Momentum으로 이해할 수 있다.
