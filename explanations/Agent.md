# 에이전트 (Agent)

에이전트는 목표를 받아 다음 행동을 정하고, 도구를 사용한 결과를 보며 작업을 이어 가는 시스템이다.

## 개발할 때

“이 버그를 고쳐 줘”라는 요청에 파일을 검색하고, 코드를 수정하고, 테스트를 실행한다. 테스트가 실패하면 결과를 읽고 다음 수정을 정한다. 여기서는 이런 코딩 에이전트를 중심으로 다룬다.

## 기억할 점

자율적으로 진행해도 권한과 도구의 범위 안에서만 행동할 수 있다. 어디까지 맡길지와 완료 조건을 정하고, 변경 결과를 검토한다.

근거: [Anthropic: 에이전트와 워크플로](https://www.anthropic.com/research/building-effective-agents).
