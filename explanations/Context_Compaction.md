# 컨텍스트 압축 (Context Compaction)

컨텍스트 압축은 긴 대화나 작업 기록을 줄여 다음 작업에 필요한 공간을 확보하는 기능이다.

## 개발할 때

긴 버그 조사 뒤에 원인, 변경 파일, 실행한 테스트, 남은 문제를 짧게 남긴다. 일부 도구는 이런 요약으로 이전 기록을 대체해 작업을 이어 간다.

## 기억할 점

압축 과정에서 세부 조건이나 실패 기록이 빠질 수 있다. 중요한 요구사항과 진행 상태는 파일로도 남기고, 요약 뒤에는 실제 코드와 테스트 결과를 다시 확인한다.

근거: [Anthropic: 장기 실행 에이전트의 하네스](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents).
