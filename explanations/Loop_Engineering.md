# 루프 엔지니어링 (Loop Engineering)

루프 엔지니어링은 AI에 반복해서 일을 맡기고, 결과를 검증하고, 다음 작업을 정하는 체계를 설계하는 일이다.

## 개발할 때

예를 들어 코드 변경마다 실행되는 자동 검사에서 실패한 작업을 정기적으로 찾는다. 원인을 분류해 에이전트에 수정을 맡기고, 테스트와 리뷰를 거쳐 처리 상태를 기록한다. 실패하면 제한된 횟수만 다시 시도하고, 진전이 없으면 사람에게 넘긴다.

## 기억할 점

2026년 실무 글에서 쓰이는 표현이며 경계가 고정된 표준은 아니다. 하네스와 겹치지만 여기서는 여러 실행에 걸친 작업 선택·검증·기록·재시도·종료에 초점을 둔다. 모델 자체의 재학습을 뜻하지 않는다.

[Ralph loop](https://ghuntley.com/ralph/)는 에이전트를 반복 호출하는 기법으로 함께 언급된다. 반복 호출만으로 성공이 보장되지는 않으므로, 완료를 입증할 검사와 시간·비용 한도, 중단 기준을 함께 둔다.

근거: [Addy Osmani: Loop Engineering](https://addyosmani.com/blog/loop-engineering/).
