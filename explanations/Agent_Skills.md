# 에이전트 스킬 (Agent Skills)

에이전트 스킬은 특정 작업의 절차와 참고 자료를 묶어 필요할 때 읽게 하는 재사용 단위다.

## 개발할 때

팀의 API 추가 절차를 스킬로 만들면 라우트 작성, 입력 검증, 테스트, 문서 갱신 순서를 함께 전달할 수 있다. Agent Skills 형식은 SKILL.md에 설명과 지침을 두고 스크립트나 자료를 함께 담을 수 있다.

## 기억할 점

스킬을 추가한다고 모델 자체가 재학습되지는 않는다. 도구 지원 여부를 확인하고, 외부 스킬의 지침과 포함된 실행 파일을 읽은 뒤 사용한다.

근거: [Agent Skills 공식 개요](https://agentskills.io/home).
