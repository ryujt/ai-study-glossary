# 사람의 개입 (Human-in-the-loop)

사람의 개입은 AI의 작업 흐름 중 필요한 지점에서 사람이 확인하거나 결정하게 하는 방식이다.

## 개발할 때

파일 조사와 로컬 테스트는 진행하게 하되, 실제 데이터 변경이나 배포 전에는 변경 내용과 검증 결과를 검토하도록 정할 수 있다. 맡길 범위는 팀의 작업 규칙과 권한에 맞춘다.

## 기억할 점

모든 행동을 매번 승인하는 것만을 뜻하지는 않는다. 영향이 큰 결정과 AI가 판단하기 어려운 조건을 구분하고, 사람이 결정할 때 필요한 근거도 함께 제공한다.
