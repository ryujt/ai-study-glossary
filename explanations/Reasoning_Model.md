# 추론 모델 (Reasoning Model)

추론 모델은 답을 내기 전에 여러 단계의 문제 풀이에 계산을 더 쓰도록 설계된 모델이다.

## 개발할 때

여러 파일에 걸친 버그의 원인을 좁히거나 설계 대안을 비교할 때 활용한다. 단순한 문구 수정은 빠른 모델로 처리하고, 복잡한 문제에 추론 기능을 써 보는 식이다.

## 기억할 점

추론을 많이 해도 정답이 보장되지는 않는다. 설정에 따라 응답 시간과 사용량이 늘어날 수 있으므로, 같은 작업의 검증 결과를 기준으로 선택한다.

근거: [Google: 추론 기능](https://ai.google.dev/gemini-api/docs/thinking).
