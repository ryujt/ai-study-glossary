# 환각 (Hallucination)

환각은 AI가 사실과 다른 내용을 그럴듯하게 만들어 내는 현상이다.

## 개발할 때

설치한 버전에는 없는 함수를 제안하거나, 존재하지 않는 설정 옵션을 설명하는 경우다. 제안한 이름을 실제 코드와 공식 문서에서 찾고, 짧은 실행으로 동작을 확인한다.

## 기억할 점

AI에게 확실한지 다시 묻는 것만으로 검증되지는 않는다. 근거 문서를 제공해도 잘못 해석할 수 있으므로, 답변의 자신감보다 확인 가능한 증거를 본다.
