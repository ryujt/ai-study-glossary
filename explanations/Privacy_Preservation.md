# 민감정보 보호 (Sensitive Data Protection)

민감정보 보호는 AI에 보내거나 AI가 접근하는 코드와 데이터에서 비밀정보와 개인정보를 관리하는 일이다.

## 개발할 때

오류 로그를 전달하기 전에 API 키, 세션 값, 실제 사용자 정보를 제거한다. 사내 코드를 다룰 때는 조직이 허용한 도구와 계정을 사용하고 외부 연결의 접근 범위를 확인한다.

## 기억할 점

데이터 보관·학습 사용·삭제 정책은 서비스, 요금제, 계약과 설정에 따라 다르다. “유료이므로 모두 보호된다”고 가정하지 않고, 사용하는 환경의 정책을 확인한다.

근거: [Claude Code: 데이터 사용 정책](https://code.claude.com/docs/en/data-usage).
