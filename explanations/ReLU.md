# ReLU (Rectified Linear Unit, 렐루)

> **ReLU는 음수는 0으로 잘라 버리고 양수는 그대로 통과시키는 활성화 함수다.** 단 한 줄 `f(x) = max(0, x)`이지만, 딥러닝을 깊게 쌓을 수 있게 만든 일등 공신이다.

## 한쪽으로만 열리는 밸브다

물이 한 방향으로만 흐르는 체크 밸브를 떠올려 보자. 정방향(양수)이면 그대로 통과시키고, 역방향(음수)이면 완전히 막는다. **ReLU가 딱 이 밸브다.**

```
f(x) = max(0, x)
```

- `x > 0`이면 `x`를 그대로 출력한다.
- `x ≤ 0`이면 0을 출력한다.

계산이라고 할 것도 없이 "음수면 0"이라는 비교 한 번이 전부다. 그래서 [시그모이드](Sigmoid.md)나 tanh처럼 지수 함수를 계산할 필요가 없어 **훨씬 빠르다.**

## 깊은 신경망의 기울기 소실을 완화한다

ReLU가 은닉층의 표준이 된 진짜 이유는 속도보다 **기울기**에 있다. 시그모이드는 양 끝에서 미분값이 0에 수렴해, 층이 깊어지면 [역전파](Backpropagation.md) 때 기울기가 사라진다. 반면 ReLU는 `x > 0` 구간에서 미분값이 항상 **1**이다. 양수 쪽으로는 기울기가 줄지 않고 그대로 흘러가므로, 깊은 신경망도 학습이 된다.

덤으로 음수 입력을 모두 0으로 만들어 **희소한(sparse)** 활성화를 낳는데, 이는 계산과 표현 측면에서 이점이 있다.

## 죽은 ReLU를 조심해야 한다

> ⚠️ **흔한 오해 — "ReLU는 그냥 선형 함수 아닌가?"**
>
> 각 조각(양수 구간, 음수 구간)은 선형이지만, `x=0`에서 꺾이는 **꺾임(kink)** 덕분에 전체로는 비선형이다. 이 비선형성이 있어야 신경망이 복잡한 패턴을 배운다. 활성화 함수가 완전히 선형이면 층을 아무리 쌓아도 하나의 선형 변환으로 줄어든다.

ReLU의 대표적 약점은 **죽은 ReLU(dying ReLU)** 문제다. 어떤 뉴런의 입력이 계속 음수라면 출력은 항상 0이고, `x < 0`에서 미분값도 0이라 기울기가 흐르지 않아 **영영 되살아나지 못한다.** 이를 보완하려 음수 구간에 작은 기울기를 주는 변형들이 나왔다.

| 변형 | 음수 구간 동작 |
|------|--------------|
| ReLU | 0 (죽을 수 있음) |
| Leaky ReLU | `0.01·x` — 작게라도 흘려보냄 |
| PReLU | 음수 구간 기울기를 학습으로 결정 |
| ELU / GELU | 음수를 부드럽게 처리, 최신 트랜스포머는 주로 GELU |

## 정리하면

- ReLU는 `f(x) = max(0, x)`, 음수는 0으로 자르고 양수는 통과시킨다.
- 지수 계산이 없어 빠르고, 양수 구간 미분이 **1**이라 기울기 소실을 완화한다.
- 조각은 선형이지만 꺾임 덕에 전체는 **비선형**이다.
- 음수에 갇힌 뉴런이 죽는 문제는 Leaky ReLU·GELU 등 변형으로 보완한다.
