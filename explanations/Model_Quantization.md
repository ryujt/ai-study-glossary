# Model Quantization (모델 양자화)

> **모델 양자화는 가중치를 표현하는 숫자의 정밀도를 낮춰(예: 32비트 실수 → 8비트 정수) 모델을 작고 빠르게 만드는 기술이다.**

## 고해상도 사진을 용량 줄여 저장하는 것과 같다

사진을 무손실 원본으로 두면 화질은 완벽하지만 용량이 어마어마하다. 웹에 올릴 때는 화질을 조금 희생해 JPEG로 압축한다. 눈으로는 거의 차이가 없는데 용량은 확 준다. **양자화가 딱 이 압축이다.** 모델의 수많은 가중치를 정밀한 32비트 실수(FP32)로 두는 대신, 8비트 정수(INT8) 같은 거친 눈금으로 근사해 표현한다.

FP32에서 INT8로 바꾸면 숫자 하나당 저장 공간이 4바이트에서 1바이트로 줄어, **모델 크기가 대략 1/4이 된다.** 게다가 정수 연산은 실수 연산보다 빠르고 전력도 덜 먹어, 추론 속도까지 올라간다. 대신 눈금이 거칠어진 만큼 미세한 값이 뭉개지는 **양자화 오차**가 생기고, 정확도가 조금 떨어질 수 있다.

## 언제 양자화하느냐로 두 방식이 갈린다

핵심 수식은 간단하다. 실수 값 `r`을 정수 `q`로 옮길 때 배율(scale) `s`와 영점(zero-point) `z`를 써서 `q = round(r / s) + z`로 매핑한다. `s`와 `z`를 잘 정하는 게 관건이고, 이를 위해 대표 데이터로 값의 분포를 재는 과정을 **칼리브레이션**이라 한다.

| 방식 | 언제 하나 | 특징 |
|------|-----------|------|
| **학습 후 양자화 (PTQ)** | 이미 학습된 모델에 적용 | 간단하고 빠름, 재학습 불필요, 정확도 손실이 상대적으로 큼 |
| **양자화 인식 학습 (QAT)** | 학습 중 양자화를 흉내내며 훈련 | 정확도 손실이 작음, 학습 비용이 듦 |

정확도가 조금 떨어져도 괜찮다면 PTQ로 충분하고, 손실을 최대한 줄여야 하면 QAT를 쓴다.

```python
import torch

# 학습된 모델에 동적 양자화(PTQ) 적용 — Linear 층을 INT8로
model_int8 = torch.quantization.quantize_dynamic(
    model, {torch.nn.Linear}, dtype=torch.qint8
)
```

## 흔한 오해

> ⚠️ **흔한 오해 — "양자화하면 모델이 멍청해진다."**
>
> 정밀도를 낮추면 오차는 생기지만, 신경망은 원래 잡음에 상당히 둔감해서 INT8 정도로는 정확도가 거의 떨어지지 않는 경우가 많다. 특히 QAT를 쓰면 손실을 몇 퍼센트포인트 안쪽으로 붙잡을 수 있다. 얻는 것(크기 1/4, 속도 향상)에 비해 잃는 것이 작다는 게 양자화가 널리 쓰이는 이유다.

## 정리하면

- 양자화는 가중치의 **숫자 정밀도를 낮춰** 모델을 작고 빠르게 만든다.
- FP32 → INT8이면 크기는 약 1/4, 추론 속도는 향상되고 대신 약간의 오차가 생긴다.
- **PTQ**는 간단하지만 손실이 크고, **QAT**는 정확도를 지키지만 학습 비용이 든다.
- 모바일·임베디드·엣지처럼 자원이 빠듯한 곳에서 특히 유용하다.
