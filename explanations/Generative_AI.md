# 생성형 AI (Generative AI)

생성형 AI는 요청에 맞춰 글, 코드, 이미지 같은 결과물을 만드는 AI다.

## 개발할 때

API 응답을 받아 화면에 표시하는 코드를 만들거나, 기존 테스트를 참고해 빠진 테스트 초안을 작성하게 한다. 완성된 결과를 바로 채택하기보다 수정할 출발점을 얻는 데 유용하다.

## 기억할 점

생성한 코드는 프로젝트 요구와 다를 수 있다. 사용한 라이브러리, 예외 처리, 데이터 노출 여부를 읽고 검증한 뒤 반영한다.
