# 워크플로 (Workflow)

워크플로는 작업을 처리할 단계와 그 순서를 정한 흐름이다.

## 개발할 때

“요구 확인 → 계획 검토 → 구현 → 검사 → 리뷰”처럼 순서를 정하고 각 단계에 AI를 활용한다. 반복되는 마이그레이션이라면 변경 목록과 검사 방법을 먼저 정해 두기 쉽다.

## 기억할 점

에이전트가 상황에 맞게 다음 행동을 고르는 방식과 구분해, 여기서는 미리 정한 흐름을 뜻한다. 정해진 절차로 충분한 일은 복잡한 자율 실행 구조가 필요하지 않을 수 있다.

근거: [Anthropic: 에이전트와 워크플로](https://www.anthropic.com/research/building-effective-agents).
