# Overfitting (과적합)

> **과적합은 모델이 학습 데이터를 "이해"하는 대신 "통째로 외워버려", 처음 보는 데이터에서 성능이 뚝 떨어지는 현상이다.**

## 시험 문제를 통째로 외운 학생과 같다

수학 원리는 이해하지 못한 채 기출문제와 답을 통째로 외운 학생을 떠올려 보자. 봤던 문제가 그대로 나오면 만점이지만, 숫자만 살짝 바뀐 새 문제 앞에서는 무너진다. **과적합된 모델이 딱 이 학생이다.** 학습 데이터에는 놀랍도록 정확하지만, 정작 써먹어야 할 새로운 데이터에서는 형편없다.

모델이 배우길 바라는 것은 데이터에 깔린 **일반적인 규칙(신호)**이다. 그런데 데이터에는 규칙과 무관한 **우연한 잡음(noise)**도 섞여 있다. 과적합은 모델이 신호뿐 아니라 이 잡음까지 외워버릴 때 일어난다.

## 모델이 너무 자유롭거나 학습이 길면 과적합된다

과적합은 대체로 두 조건에서 심해진다.

- **모델이 데이터에 비해 지나치게 복잡할 때** — 파라미터가 많아 표현력이 남아돌면, 남는 힘으로 잡음까지 맞추려 든다.
- **같은 데이터를 너무 오래 학습할 때** — 반복이 길어질수록 모델은 점점 데이터 하나하나에 밀착한다.

학습이 진행되면서 학습 오차는 계속 줄지만 검증 오차는 어느 순간부터 다시 오른다. **이 갈라지는 지점이 과적합이 시작되는 곳이다.**

## 흔한 오해

> ⚠️ **흔한 오해 — "학습 정확도가 높으니 좋은 모델이다."**
>
> 학습 정확도만 높은 것은 오히려 위험 신호일 수 있다. 학습 성능과 검증·테스트 성능의 **격차**가 과적합의 진짜 지표다. 학습 99%, 검증 70%라면 그 모델은 외웠을 뿐 배우지 못했다.

## 어떻게 막나

| 방법 | 핵심 아이디어 |
|------|--------------|
| 데이터 늘리기 | 외울 수 없을 만큼 예시를 준다 ([데이터 증강](Data_Augmentation.md)) |
| 정규화 | 가중치가 커지지 않게 벌점을 준다 ([정규화](Regularization.md)) |
| 드롭아웃 | 학습 중 뉴런 일부를 꺼서 특정 경로에 의존하지 못하게 한다 ([드롭아웃](Dropout.md)) |
| 조기 종료 | 검증 오차가 오르기 시작하면 학습을 멈춘다 ([조기 종료](Early_Stopping.md)) |
| 모델 단순화 | 파라미터 수를 줄여 표현력을 낮춘다 |

## 정리하면

- 과적합은 모델이 **일반 규칙 대신 학습 데이터의 잡음까지 외운** 상태다.
- 증상은 **낮은 학습 오차 + 높은 검증 오차**, 즉 둘 사이의 큰 격차다.
- 모델이 복잡하거나 학습이 길수록 심해진다.
- 데이터 증강·정규화·드롭아웃·조기 종료로 막는다.
- 반대편 극단, 즉 규칙조차 못 배운 상태는 [과소적합](Underfitting.md)이다.
