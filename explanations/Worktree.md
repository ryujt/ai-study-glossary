# 워크트리 (Git Worktree)

Git 워크트리는 하나의 저장소에서 여러 작업 디렉터리를 두고 보통 서로 다른 브랜치를 체크아웃하는 기능이다.

## 개발할 때

한 디렉터리에서는 사람이 기능을 개발하고, 다른 디렉터리에서는 에이전트가 별도 브랜치의 버그를 고치게 한다. 서로의 편집 중인 파일을 건드리는 일을 줄일 수 있다.

## 기억할 점

파일 공간을 나눠도 변경을 합칠 때 충돌할 수 있다. 포트, 데이터베이스, 외부 서비스는 그대로 공유될 수 있으며, 워크트리 자체는 보안 격리 기능이 아니다.

근거: [Git: git-worktree 공식 문서](https://git-scm.com/docs/git-worktree).
