# 저장소 지침 (Repository Instructions)

저장소 지침은 코딩 에이전트가 프로젝트에서 따라야 할 규칙과 작업 방법을 적은 문서다.

## 개발할 때

AGENTS.md 같은 파일에 디렉터리 역할, 테스트 명령, 코드 스타일, 수정에 주의할 파일을 적는다. 처음 합류한 동료에게 알려 줄 내용을 짧게 정리하면 된다.

## 기억할 점

읽는 파일명과 적용 범위, 지침의 우선순위는 도구마다 다르다. 문서에 적었다고 실행이 강제되지는 않으며, 명령이 바뀌면 지침도 함께 갱신한다.

근거: [AGENTS.md 공식 안내](https://agents.md/).
