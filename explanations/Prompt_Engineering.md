# 프롬프트 엔지니어링 (Prompt Engineering)

프롬프트 엔지니어링은 AI가 원하는 작업을 하도록 요청의 내용과 구성을 다듬는 일이다.

## 개발할 때

버그 수정을 맡길 때 재현 절차와 기대 동작을 붙이고, 수정할 범위를 좁힌다. 결과가 빗나가면 모호했던 조건을 고쳐 같은 사례에서 나아졌는지 확인한다.

## 기억할 점

특별한 문구를 외우는 것보다 빠진 조건을 채우는 편이 유용하다. 필요한 코드나 실행 도구가 없다면 요청만 길게 바꿔도 해결되지 않을 수 있다.

근거: [Anthropic: 컨텍스트 엔지니어링](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents).
