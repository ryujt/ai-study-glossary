# Distributed Computing (분산 컴퓨팅)

> **분산 컴퓨팅은 한 대로는 못 감당할 일을 여러 대의 컴퓨터에 나눠 맡기고, 결과를 다시 합쳐 하나의 작업으로 완성하는 방식이다.**

## 혼자 못 드는 짐은 여럿이 나눠 든다

거대한 짐 하나를 혼자 들 수 없으면 여러 사람이 나눠 든다. 컴퓨팅도 같다. 데이터가 한 대의 메모리·디스크를 넘어서거나, 계산이 한 대의 CPU로는 며칠 걸릴 때, **일을 쪼개 여러 노드에 뿌리고 각자 처리하게 한 뒤 결과를 모은다.**

관건은 두 가지다. **일을 어떻게 잘 쪼개느냐**, 그리고 **노드끼리 어떻게 소통하느냐(네트워크)**다. 노드 하나가 죽어도 전체가 멈추지 않게 하는 내결함성도 핵심 숙제다.

## 딥러닝과 만나는 지점

거대한 모델·데이터를 학습할 때 분산 컴퓨팅은 필수다.

- **데이터 병렬**: 같은 모델을 여러 GPU에 복제하고, 데이터를 나눠 각자 [기울기](Gradient_Descent.md)를 구한 뒤 합친다.
- **모델 병렬**: 모델 자체가 너무 커서 한 GPU에 안 들어가면, 모델을 쪼개 여러 장치에 얹는다.

## 흔한 오해

> ⚠️ **흔한 오해 — "노드를 2배로 늘리면 2배 빨라진다."**
>
> 노드끼리 데이터를 주고받는 **통신 비용**과 결과를 합치는 대기 시간 때문에, 늘린 만큼 선형으로 빨라지지 않는다. 어느 지점을 넘으면 통신 오버헤드가 계산 이득을 잡아먹는다.

## 정리하면

- 분산 컴퓨팅은 **큰 일을 여러 노드에 나눠 처리**하는 방식이다.
- 일 쪼개기·노드 간 통신·내결함성이 핵심 과제다.
- 대규모 모델 학습에서 데이터 병렬·모델 병렬로 쓰인다.
- 통신 비용 때문에 노드 수와 속도가 선형 비례하진 않는다.
