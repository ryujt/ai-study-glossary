# First‑order Logic (일차논리)

> **일차논리는 "모든", "어떤" 같은 한정사와 대상·관계를 써서, 개별 사물에 대한 일반 명제까지 정밀하게 표현하는 논리 체계다.**

## 명제논리로는 "모든 사람"을 한 문장에 못 담는다

명제논리는 "비가 온다", "땅이 젖는다"처럼 문장 하나를 통째로 참/거짓으로만 다룬다. 그래서 **"모든 사람은 죽는다"** 같은, 개별 대상 전체를 아우르는 말을 제대로 못 쓴다. 사람마다 문장을 따로 만들어야 하니 무한히 늘어난다.

일차논리는 문장 안을 뜯어본다. **대상(소크라테스), 술어/관계(~는 사람이다), 한정사(모든·어떤)**를 도입해, 개별 사물에 대한 일반 규칙을 한 줄로 적는다.

```
∀x ( 사람(x) → 죽는다(x) )       # 모든 x에 대해, x가 사람이면 x는 죽는다
∃x ( 사람(x) ∧ 천재(x) )         # 어떤 x는 사람이면서 천재다
```

- **∀ (전칭)**: "모든 ~에 대해"
- **∃ (존재)**: "어떤 ~가 있다"

## 흔한 오해

> ⚠️ **흔한 오해 — "일차논리와 술어논리는 다른 것이다."**
>
> 보통 같은 것을 가리킨다. [술어논리](Predicate_Logic.md)에서 한정사가 **대상(개체)에만** 걸리는 버전이 일차논리다. 술어 자체에까지 한정사를 거는 것은 고차논리다. 즉 "일차"는 한정하는 범위가 개체 수준이라는 뜻이다.

## 정리하면

- 일차논리는 **대상·관계·한정사(∀·∃)**로 개별 사물의 일반 명제를 표현한다.
- 명제논리의 표현력 한계("모든 ~")를 넘어선다.
- 한정사가 개체에만 걸리는 논리이고, 술어논리와 사실상 같은 말로 쓰인다.
