# 에이전트 하네스 (Agent Harness)

에이전트 하네스는 모델을 감싸 도구 실행, 작업 상태, 권한, 반복 처리를 제공하는 소프트웨어 환경이다.

## 개발할 때

모델이 테스트 실행을 요청하면 하네스가 명령을 실행하고 결과를 다시 전달한다. 파일 편집, 대화 기록 관리, 실행 제한도 이런 주변 환경의 역할이다.

## 기억할 점

같은 모델도 하네스가 제공하는 도구와 규칙에 따라 할 수 있는 일이 달라진다. 이 용어의 범위는 자료마다 조금씩 다르며, 특정 제품 하나의 이름은 아니다.
