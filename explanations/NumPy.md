# NumPy (넘파이)

> **NumPy는 파이썬에서 숫자 배열을 빠르게 다루는 과학 계산 라이브러리다. 파이썬 리스트로는 느린 대규모 수치 연산을 C 속도로 처리한다.**

## 파이썬 리스트를 진짜 계산 도구로 바꿔 준다

파이썬 리스트로 백만 개 숫자에 각각 2를 곱하려면 `for`문을 돌려야 하고, 이건 느리다. **NumPy는 이 반복을 없앤다.** 배열 전체에 `arr * 2` 한 줄이면 끝이고, 속도는 순수 파이썬 루프보다 수십 배 빠르다. 그래서 [Pandas](Pandas.md), [Scikit-learn](Scikitlearn.md), 딥러닝 프레임워크까지 파이썬 데이터 생태계 거의 전부가 NumPy 위에 서 있다.

빠른 비결은 두 가지다.

- **연속된 메모리 + C 구현** — 같은 타입의 데이터를 메모리에 촘촘히 붙여 저장하고, 연산은 컴파일된 C 코드가 처리한다.
- **벡터화(vectorization)** — 파이썬 루프 대신 배열 단위 연산으로 반복을 C 내부로 밀어 넣는다.

## 핵심은 ndarray, 무기는 브로드캐스팅이다

NumPy의 중심 자료구조는 다차원 배열 `ndarray`다. 모양(shape)을 가진 격자에 같은 타입의 숫자가 담긴다.

```python
import numpy as np

a = np.array([[1, 2, 3],
              [4, 5, 6]])      # shape (2, 3)

print(a.shape)                 # (2, 3)
print(a * 2)                   # 모든 원소에 2 곱하기 (벡터화)
print(a.mean(axis=0))          # 열별 평균 -> [2.5 3.5 4.5]
```

모양이 다른 배열끼리도 규칙에 따라 자동으로 맞춰 연산하는 것이 **브로드캐스팅**이다. 작은 배열을 큰 배열 모양에 맞춰 늘려 계산한다.

```python
matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])   # shape (2, 3)
row = np.array([10, 20, 30])     # shape (3,)

print(matrix + row)              # row가 각 행에 더해진다
# [[11 22 33]
#  [14 25 36]]
```

> 💡 **참고 — 딥러닝의 "텐서"는 ndarray의 확장이다.** [PyTorch](PyTorch.md)의 텐서나 TensorFlow의 텐서는 GPU 연산과 자동 미분이 붙은 다차원 배열로, NumPy의 ndarray와 사고방식이 거의 같다. NumPy를 익히면 텐서도 자연스럽게 이해된다.

## 흔한 오해

> ⚠️ **흔한 오해 — "NumPy 배열은 그냥 파이썬 리스트의 빠른 버전이다."**
>
> 겉보기는 비슷해도 성질이 다르다. 리스트는 서로 다른 타입을 섞어 담을 수 있지만, ndarray는 **한 가지 타입만** 담아 메모리를 촘촘히 쓰고 그 대가로 속도를 얻는다. 또 `arr * 2`는 리스트라면 원소 두 배 복제지만 ndarray에서는 원소별 곱셈이다. 리스트로 생각하면 함정에 빠진다.

## 정리하면

- NumPy는 대규모 수치 연산을 **C 속도로** 처리하는 파이썬의 기반 라이브러리다.
- 중심은 같은 타입 숫자를 담는 다차원 배열 **ndarray**다.
- **벡터화**로 루프를 없애고, **브로드캐스팅**으로 모양이 다른 배열도 연산한다.
- Pandas·Scikit-learn·딥러닝 프레임워크가 모두 NumPy 위에 서 있다.
