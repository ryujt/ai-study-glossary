# Self‑Attention (셀프 어텐션)

> **셀프 어텐션은 한 문장 안의 각 단어가 "나는 같은 문장의 어떤 단어를 얼마나 참고해야 하나"를 스스로 계산해, 문맥을 담은 표현을 만드는 메커니즘이다.**

## "그것"이 무엇을 가리키는지 스스로 찾아낸다

"그 동물은 길을 안 건넜다. 너무 피곤했기 때문이다." 여기서 "피곤한" 것은 동물일까 길일까? 사람은 문맥으로 "동물"임을 안다. 셀프 어텐션은 각 단어가 **문장 속 다른 모든 단어와의 관련도를 저울질**해, "피곤"이 "동물"을 강하게 참고하도록 가중치를 매긴다.

핵심은 세 벡터다. 각 단어는 자신을 **쿼리(Query, 질문)**·**키(Key, 이름표)**·**밸류(Value, 알맹이)**로 변환한다.

1. 내 쿼리를 모든 단어의 키와 견줘 **관련도 점수**를 낸다.
2. 점수를 [소프트맥스](Softmax.md)로 정규화해 가중치로 만든다.
3. 그 가중치로 모든 단어의 밸류를 **가중 합**한다 → 문맥이 밴 새 표현.

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √d) · V
```

## 흔한 오해

> ⚠️ **흔한 오해 — "셀프 어텐션은 순서대로 한 단어씩 처리한다."**
>
> 반대다. 모든 단어의 관련도를 **한꺼번에 병렬로** 계산한다. [순환 신경망(RNN)](Recurrent_Neural_Network___RNN.md)의 순차 처리를 없앤 이 점이 [트랜스포머](Transformer.md)를 빠르고 강하게 만든 결정타다. 대신 순서 정보가 사라지므로 위치 인코딩을 따로 더한다.

## 정리하면

- 셀프 어텐션은 각 단어가 **같은 문장의 어떤 단어를 참고할지 스스로 계산**한다.
- 쿼리·키·밸류 세 벡터로 관련도를 재고 밸류를 가중 합한다.
- 순차가 아니라 **병렬**로 처리해 빠르다.
- 트랜스포머·GPT·BERT의 심장이다.
