# Confusion Matrix (혼동 행렬)

> **혼동 행렬은 분류 모델이 "무엇을 맞히고 무엇을 어떻게 틀렸는지"를 실제값 대 예측값의 표 하나로 펼쳐 보여 주는 도구다.**

## 정확도 하나로는 안 보이는 "틀린 방식"을 드러낸다

정확도는 "몇 %를 맞혔다"는 단 하나의 숫자다. 그런데 암 검진에서 정확도 95%가 "정상을 잘 맞혔다"인지 "암을 놓쳤다"인지는 전혀 다른 이야기다. 혼동 행렬은 **맞힘과 틀림을 네 칸으로 쪼개** 이 차이를 드러낸다.

|  | 예측: 양성 | 예측: 음성 |
|---|-----------|-----------|
| **실제: 양성** | TP (제대로 잡음) | FN (놓침) |
| **실제: 음성** | FP (헛짚음) | TN (제대로 넘김) |

- **TP/TN**: 맞힌 경우.
- **FP(거짓 양성)**: 아닌데 양성이라 함 — 헛경보.
- **FN(거짓 음성)**: 맞는데 음성이라 함 — 놓침.

이 네 칸에서 거의 모든 분류 지표가 파생된다.

```
정밀도 = TP / (TP + FP)      # 양성이라 한 것 중 진짜
재현율 = TP / (TP + FN)      # 진짜 양성 중 잡아낸 것
정확도 = (TP + TN) / 전체
```

## 흔한 오해

> ⚠️ **흔한 오해 — "FP와 FN은 그냥 둘 다 '틀린 것'이라 똑같이 나쁘다."**
>
> 문제에 따라 무게가 전혀 다르다. 암 검진에선 놓침(FN)이 치명적이고, 스팸 필터에선 중요 메일을 스팸 처리하는 헛짚음(FP)이 더 아프다. 혼동 행렬을 보는 이유가 바로 **이 둘을 구분**하기 위해서다.

## 정리하면

- 혼동 행렬은 분류 결과를 **TP·FP·FN·TN 네 칸**으로 펼친 표다.
- 정확도 하나로 감춰지는 "틀린 방식"을 드러낸다.
- [정밀도](Precision.md)·[재현율](Recall.md)·[F1](F1_Score.md) 등 대부분의 지표가 여기서 나온다.
- FP와 FN의 비용은 문제마다 다르다.
