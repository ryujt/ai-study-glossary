# 도구 사용 (Tool Use / Function Calling)

도구 사용은 모델이 파일 검색이나 명령 실행 같은 외부 기능의 호출을 요청하고, 프로그램이 이를 실행하는 방식이다.

## 개발할 때

모델이 “이 테스트 명령을 실행하라”는 호출과 인자를 만들면 코딩 도구가 실행한다. 실행 결과가 모델에 돌아가고, 모델은 그 결과를 보고 다음 행동을 정한다. function calling도 이런 연결을 가리킨다.

## 기억할 점

답변에 “테스트했다”고 적힌 것과 실제 실행 기록은 다르다. 어떤 도구를 어떤 인자로 실행했고 결과가 무엇인지 확인한다. 허용하지 않은 행동은 실행 환경에서 제한한다.
