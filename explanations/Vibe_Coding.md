# 바이브 코딩 (Vibe Coding)

바이브 코딩은 자연어로 원하는 것을 말하고, 생성된 코드의 세부를 충분히 읽지 않은 채 실행 결과를 보며 만드는 방식을 가리킨다.

## 개발할 때

작은 아이디어를 화면으로 빠르게 확인할 때 이 표현을 자주 접한다. AI의 도움을 받아도 코드를 읽고 설계와 테스트를 검토한다면, 모든 과정을 바이브 코딩이라고 부를 필요는 없다.

## 기억할 점

이 용어는 넓은 뜻으로도 쓰인다. 이 용어집은 코드 이해와 검토를 건너뛰는 쪽의 의미로 구분한다. 시제품을 서비스로 옮길 때는 인증, 오류 처리, 데이터 관리를 다시 살펴본다.
