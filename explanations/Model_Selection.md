# 모델 선택 (Model Selection)

모델 선택은 작업에 필요한 능력과 응답 시간, 비용을 비교해 사용할 모델을 고르는 일이다.

## 개발할 때

단순한 코드 설명과 여러 모듈에 걸친 설계 변경에 같은 설정이 필요하지는 않다. 팀에서 자주 하는 작업을 같은 조건으로 수행해 결과와 수정에 든 시간을 비교한다.

## 기억할 점

모델 이름이나 순위만으로 고르기 어렵다. 컨텍스트 한도, 추론 설정, 도구 지원, 데이터 정책도 살펴본다. 도구나 지침이 부족해 생긴 실패는 모델을 바꿔도 반복될 수 있다.

근거: [Claude Code: 사용량과 비용 관리](https://code.claude.com/docs/en/costs).
