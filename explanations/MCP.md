# MCP (Model Context Protocol)

MCP는 AI 애플리케이션이 외부 도구와 자료에 연결할 때 사용하는 공통 통신 규약이다.

## 개발할 때

코딩 도구에 이슈 관리 서비스의 MCP 서버를 연결하면, 제공된 기능으로 이슈를 읽거나 작업에 필요한 정보를 가져올 수 있다. 서버는 로컬 프로그램일 수도 원격 서비스일 수도 있다.

## 기억할 점

MCP 자체가 데이터를 기억하거나 연결 대상을 신뢰할 수 있게 만드는 것은 아니다. 제공자, 접근 권한, 전송되는 데이터를 확인한다. 실제로 가능한 행동은 서버와 연결한 앱에 따라 달라진다.

근거: [MCP 공식 아키텍처 문서](https://modelcontextprotocol.io/docs/learn/architecture).
