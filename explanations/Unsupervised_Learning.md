# Unsupervised Learning (자율학습)

> **자율학습은 정답(레이블) 없이 데이터만 보고, 그 안에 숨은 구조·패턴·관계를 스스로 찾아내는 학습 방식이다.**

## 정답지 없이 상자 속 물건을 스스로 분류하는 것과 같다

이름표 하나 없는 물건이 잔뜩 든 상자를 주고 "정리해봐"라고만 한다고 하자. 누가 "이건 공, 저건 책"이라고 알려주지 않아도, 우리는 모양·크기·색이 비슷한 것끼리 자연스럽게 무더기로 묶는다. **자율학습이 하는 일이 이것이다.** 정답을 주는 [지도학습](Supervised_Learning.md)과 달리, 자율학습은 **레이블 없이 데이터의 생김새만으로** 비슷한 것을 묶고 구조를 드러낸다.

목표가 "정답 맞히기"가 아니다 보니, 데이터를 **탐색하고 이해하는** 데 강하다. 무엇을 찾아야 할지 미리 모를 때 특히 쓸모 있다.

## 무엇을 찾느냐에 따라 크게 네 갈래로 쓴다

| 용도 | 무엇을 하나 | 예시 |
|---|---|---|
| 군집화(Clustering) | 비슷한 데이터를 무더기로 묶기 | 고객을 성향별 그룹으로 나누기 |
| 차원 축소(Dimensionality Reduction) | 핵심 특징만 남겨 데이터를 압축 | 수백 개 특징을 2~3개로 줄여 시각화 |
| 이상 탐지(Anomaly Detection) | 나머지와 크게 다른 데이터 골라내기 | 카드 부정 사용, 설비 고장 징후 |
| 연관 규칙(Association Rule) | 함께 나타나는 항목 관계 찾기 | "기저귀 산 사람은 맥주도 산다" |

작동 원리는 알고리즘마다 다르지만 공통점은 **데이터 자체의 통계적 성질에 기댄다**는 것이다. 예를 들어 [K-means](Kmeans_Algorithm.md)는 데이터를 k개 무더기로 나눌 중심점을 반복해서 찾아가고, [오토인코더](Autoencoder.md)는 데이터를 좁은 통로로 압축했다 복원하며 핵심 표현을 배운다.

## 흔한 오해

> ⚠️ **흔한 오해 — "정답이 없으니 결과가 맞는지 확인할 방법도 없다."**
>
> 정답 레이블이 없어 지도학습처럼 정확도를 재긴 어렵지만, 평가가 불가능한 것은 아니다. 군집이 얼마나 잘 뭉치고 서로 떨어졌는지(실루엣 점수 등)로 품질을 가늠하고, 결과를 사람이 해석해 의미를 확인한다. **다만 "정답 대비 몇 % 맞음" 같은 명확한 잣대가 없다는 점은 자율학습의 본질적 어려움이다.**

## 정리하면

- 자율학습은 **레이블 없이** 데이터 속 구조·패턴을 스스로 찾는다.
- 대표 용도는 **군집화, 차원 축소, 이상 탐지, 연관 규칙**이다.
- 무엇을 찾을지 모를 때 데이터를 **탐색·이해**하는 데 강하다.
- 정답이 없어 성능 평가가 지도학습보다 까다롭다.
