# 에이전트 메모리 (Agent Memory)

에이전트 메모리는 다음 작업에서도 참고할 수 있도록 저장해 둔 정보다.

## 개발할 때

프로젝트의 테스트 명령, 이미 내린 결정, 미완료 작업을 파일이나 작업 관리 도구에 남긴다. 새 대화가 시작되면 이 기록을 읽어 같은 조사를 반복하는 일을 줄인다.

## 기억할 점

대화를 나누는 동안 모델 자체가 새 지식을 영구 학습한다는 뜻은 아니다. 도구마다 저장·검색 방식이 다르며, 오래된 기록은 실제 코드와 대조해 고친다.

근거: [Claude Code: 프로젝트 지침과 메모리](https://code.claude.com/docs/en/memory).
