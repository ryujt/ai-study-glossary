# ROC Curve (ROC 곡선)

> **ROC 곡선은 분류 기준(임계값)을 0에서 1까지 훑으며 "놓치지 않는 정도"와 "헛경보의 정도"가 어떻게 맞바뀌는지를 한 장에 그린 그래프다.**

## 화재 경보기의 민감도를 어디에 맞출지의 문제다

화재 경보기를 아주 예민하게 맞추면 불이 나면 무조건 울리지만, 담배 연기에도 울려 헛경보가 잦다. 반대로 둔감하게 맞추면 헛경보는 없지만 진짜 불을 놓칠 위험이 커진다. **어느 한 설정이 정답이 아니라, 민감도를 조절할 때마다 "진짜를 잡는 비율"과 "헛경보 비율"이 함께 움직인다.** ROC 곡선은 이 모든 설정을 한 곡선으로 이어 그린 것이다.

분류 모델은 대개 "양성일 확률 0.8" 같은 점수를 낸다. 이 점수를 양성/음성으로 가르는 기준선이 **임계값(threshold)**이다. 임계값을 바꾸면 예측 결과가 통째로 바뀌므로, 성능도 하나의 숫자가 아니라 임계값에 따라 변하는 곡선으로 봐야 한다.

## 세로축은 진짜를 잡는 비율, 가로축은 헛경보 비율이다

ROC 곡선은 임계값을 1에서 0까지 낮춰가며 두 값의 쌍을 찍어 잇는다.

- **세로축 — TPR (True Positive Rate, 재현율/민감도):** 실제 양성 중 양성으로 맞힌 비율. `TP / (TP + FN)`. 높을수록 놓치지 않는다.
- **가로축 — FPR (False Positive Rate):** 실제 음성 중 양성으로 잘못 부른 비율. `FP / (FP + TN)`. 낮을수록 헛경보가 적다.

이상적인 모델은 헛경보 없이(FPR=0) 다 잡아내(TPR=1) 왼쪽 위 모서리 `(0, 1)`에 붙는다. 아무 정보 없이 무작위로 찍는 모델은 대각선 `y = x`를 그린다. **곡선이 왼쪽 위로 볼록할수록 좋은 모델**이고, 대각선에 가까우면 찍는 것과 다를 바 없다.

> ⚠️ **흔한 오해 — "가로축과 세로축이 정밀도와 재현율이다."**
>
> ROC 곡선의 가로축은 정밀도(Precision)가 아니라 **FPR**이다. 정밀도-재현율을 그리는 것은 별개인 PR 곡선이다. 클래스가 심하게 불균형할 때는 FPR이 좋아 보여도 정밀도가 낮을 수 있어, ROC보다 PR 곡선이 더 정직한 경우가 있다.

## 곡선 아래 면적 하나로 요약하면 AUC다

곡선 전체를 하나의 숫자로 요약한 것이 **AUC(Area Under the Curve)**, 곡선 아래 면적이다.

| AUC 값 | 해석 |
|--------|------|
| 1.0 | 완벽한 분류 |
| 0.9 ~ 1.0 | 매우 우수 |
| 0.7 ~ 0.9 | 쓸 만함 |
| 0.5 | 무작위 추측과 동일 |
| < 0.5 | 무작위보다 나쁨 (예측을 뒤집는 게 낫다) |

AUC는 "무작위로 고른 양성 하나가 무작위로 고른 음성 하나보다 높은 점수를 받을 확률"로도 해석된다. **임계값을 고정하지 않고 모델의 순위 매기는 능력 전체를 평가**하므로, 여러 모델을 임계값과 무관하게 비교할 때 편리하다. 자세한 것은 [AUC](AUC.md) 참고.

## 정리하면

- ROC 곡선은 임계값을 훑으며 **TPR(세로) 대 FPR(가로)**의 관계를 그린 곡선이다.
- 왼쪽 위로 볼록할수록 좋고, 대각선은 무작위 추측이다.
- 곡선을 한 수로 요약한 것이 **AUC**이며, 0.5는 무작위, 1.0은 완벽이다.
- 임계값에 독립적으로 모델을 비교할 수 있지만, 클래스 불균형이 심하면 PR 곡선이 더 정직하다.
