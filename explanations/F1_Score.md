# F1 Score (F1 점수)

> **F1 점수는 [정밀도](Precision.md)와 [재현율](Recall.md)의 조화 평균으로, 두 지표 중 어느 하나라도 낮으면 함께 낮아지는 균형 점수다.**

## 두 마리 토끼를 모두 잡았는지 한 숫자로 본다

분류 성능은 보통 두 각도로 잰다. [정밀도](Precision.md)는 "긍정이라 답한 것 중 진짜 긍정이 얼마나 되나"(헛다리를 안 짚나)이고, [재현율](Recall.md)은 "실제 긍정 중 얼마나 잡아냈나"(놓치지 않나)다. 이 둘은 대개 한쪽을 올리면 다른 쪽이 내려가는 **트레이드오프** 관계다. 그래서 둘 다 봐야 하는데, 지표가 두 개면 모델을 한 줄로 세우기 불편하다. **F1 점수는 이 둘을 하나로 합친 숫자다.**

## 산술 평균이 아니라 조화 평균인 이유

F1은 단순 평균이 아니라 **조화 평균(harmonic mean)**이다.

```
F1 = 2 · (정밀도 · 재현율) / (정밀도 + 재현율)
```

왜 굳이 조화 평균일까. 산술 평균은 한쪽이 극단적으로 낮아도 다른 쪽이 높으면 그럭저럭 나온다. 예를 들어 정밀도 1.0, 재현율 0.0이면 산술 평균은 0.5지만, **조화 평균은 0**이다. 조화 평균은 **작은 값에 끌려간다.** 그래서 F1이 높으려면 정밀도와 재현율이 **둘 다** 높아야 한다. 한쪽만 잘해서는 좋은 점수를 못 받는다.

혼동 행렬로 각 값을 정의하면 이렇다.

|  | 실제 양성(P) | 실제 음성(N) |
|---|---|---|
| **예측 양성** | TP (참 양성) | FP (거짓 양성) |
| **예측 음성** | FN (거짓 음성) | TN (참 음성) |

- `정밀도 = TP / (TP + FP)`
- `재현율 = TP / (TP + FN)`
- `F1 = 2·TP / (2·TP + FP + FN)`

## 흔한 오해

> ⚠️ **흔한 오해 — "F1은 정밀도와 재현율의 평균이니까 (0.9+0.5)/2 = 0.7이다."**
>
> 조화 평균이라 그렇게 계산되지 않는다. 정밀도 0.9, 재현율 0.5면 F1 = 2·(0.9·0.5)/(0.9+0.5) ≈ 0.64로, 산술 평균 0.7보다 낮다. 낮은 쪽으로 끌린다.

> 💡 **참고 — F1은 정밀도와 재현율을 똑같이 중요하게 본다.**
>
> 어느 한쪽이 더 중요한 상황(예: 암 진단은 재현율이 더 중요)이라면, 가중치를 둔 `Fβ` 점수를 쓴다. β>1이면 재현율에, β<1이면 정밀도에 무게를 더 싣는다. F1은 β=1인 특수한 경우다.

## 언제 쓰나

| 상황 | F1이 적합한가 |
|------|--------------|
| 클래스가 심하게 [불균형](Imbalanced_Data.md)한 경우 | 적합 — 정확도는 다수 클래스에 속아도 F1은 소수 클래스 성능을 드러낸다 |
| 정밀도·재현율이 둘 다 중요한 경우 | 적합 — 한쪽만 높으면 점수가 깎인다 |
| 참 음성(TN)이 중요한 경우 | 부적합 — F1 공식에 TN이 들어가지 않는다 |

## 정리하면

- F1은 [정밀도](Precision.md)와 [재현율](Recall.md)의 **조화 평균**이라 둘 다 높아야 높아진다.
- `F1 = 2·(P·R)/(P+R)`, 한쪽이 0이면 F1도 0이다.
- 클래스가 [불균형](Imbalanced_Data.md)할 때 정확도보다 신뢰할 만한 단일 지표다.
- TN을 반영하지 않으므로, 음성 탐지가 중요하면 다른 지표를 함께 본다.
