# 호출 제한 (Rate Limit)

호출 제한은 일정 시간 동안 보낼 수 있는 요청 수나 처리할 수 있는 토큰 양 등에 두는 한도다.

## 개발할 때

여러 에이전트가 동시에 요청하면 사용 가능 금액이 남아 있어도 제한에 걸릴 수 있다. 실행 수를 줄이거나, 서비스가 안내하는 대기 시간 뒤 다시 시도하도록 처리한다.

## 기억할 점

계속 즉시 재시도하면 해결되지 않을 수 있다. API의 시간당 처리 한도와 구독 도구의 기간별 사용량 한도는 구분한다. 정확한 기준은 서비스·모델·계정에 따라 달라진다.

근거: [Google: API 호출 제한](https://ai.google.dev/gemini-api/docs/rate-limits).
