# Data Augmentation (데이터 증강)

> **데이터 증강은 갖고 있는 데이터에 조금씩 변형을 가해 학습 데이터를 인위적으로 불려, 모델이 더 다양한 상황에 견디도록 만드는 기법이다.**

## 사진 한 장을 여러 장처럼 써먹는 것이다

고양이 사진 1,000장으로 분류기를 학습시킨다고 하자. 새 사진을 모으기는 비싸고 느리다. 대신 **가진 사진을 좌우로 뒤집고, 살짝 돌리고, 밝기를 바꾸면** 하나의 사진에서 여러 변형본이 나온다. 사람 눈에는 여전히 같은 고양이지만, 모델에게는 새로운 학습 예시다. **데이터 증강은 이렇게 라벨은 그대로 둔 채 입력만 그럴듯하게 흔들어 데이터를 늘리는 것이다.**

핵심은 **변형해도 정답이 바뀌지 않아야** 한다는 점이다. 고양이를 뒤집어도 고양이지만, 숫자 6을 180도 돌리면 9가 되어 라벨이 깨진다. 그래서 증강은 데이터 종류마다 맞게 골라야 한다.

## 유형마다 안전한 변형이 다르다

| 데이터 | 흔한 증강 |
|--------|-----------|
| 이미지 | 좌우 반전, 회전, 확대·자르기, 밝기·색상 변경, 노이즈 추가 |
| 텍스트 | 동의어 치환, 역번역(다른 언어로 번역 후 되돌리기), 단어 임의 삭제 |
| 오디오 | 시간 이동, 속도·음높이 변경, 배경 소음 추가 |

증강은 학습 데이터가 담지 못한 변형을 미리 보여 줌으로써, 모델이 **본질(고양이의 생김새)에 집중하고 곁가지(방향·밝기)에 흔들리지 않게** 한다. 그 결과 새 데이터에 대한 일반화가 좋아지고 [과적합](Overfitting.md)이 줄어든다.

```python
# PyTorch로 이미지 증강 파이프라인 정의
import torchvision.transforms as T

augment = T.Compose([
    T.RandomHorizontalFlip(p=0.5),   # 좌우 반전
    T.RandomRotation(degrees=15),    # ±15도 회전
    T.ColorJitter(brightness=0.2),   # 밝기 흔들기
    T.ToTensor(),
])
# 학습 때마다 매번 다르게 변형되어 들어간다
```

> ⚠️ **흔한 오해 — "데이터를 늘리는 거니까 정보량도 늘어난다."**
>
> 새 정보가 생기는 게 아니다. 변형본은 원본과 강하게 겹친다. 증강이 주는 것은 새 지식이 아니라 **불변성(invariance) 힌트**, 즉 "이런 변형에는 흔들리지 마"라는 신호다. 그래서 진짜 다양한 새 데이터를 모으는 것을 완전히 대체하지는 못한다. 또 검증·테스트 데이터에는 증강을 적용하지 않는다.

## 정리하면

- 데이터 증강은 **라벨을 유지한 채 입력을 흔들어** 학습 데이터를 불리는 기법이다.
- 변형해도 정답이 바뀌지 않아야 하며, 데이터 종류마다 안전한 변형이 다르다.
- 모델이 곁가지에 흔들리지 않게 해 **일반화를 높이고 과적합을 줄인다.**
- 새 정보를 만드는 게 아니라 불변성 힌트를 주는 것이라, 실제 데이터 수집을 완전히 대신하지는 못한다.
