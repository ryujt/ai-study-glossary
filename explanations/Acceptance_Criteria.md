# 완료 조건 (Acceptance Criteria)

완료 조건은 작업을 끝냈다고 판단할 수 있도록 관찰 가능한 결과로 적은 기준이다.

## 개발할 때

“로그인을 잘 처리한다” 대신 “세션 만료 뒤 보호된 페이지에 접근하면 로그인 화면으로 이동한다”처럼 적는다. 이를 테스트나 실제 화면 조작으로 확인한다.

## 기억할 점

AI의 완료 보고만으로 충족됐다고 판단하지 않는다. 검사 명령, 결과, 확인하지 못한 항목을 함께 본다. 일부 테스트 통과와 전체 요구 충족도 구분한다.

근거: [Claude Code: 개발 작업 가이드](https://code.claude.com/docs/en/best-practices).
