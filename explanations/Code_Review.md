# AI 생성 코드 리뷰 (Reviewing AI-generated Code)

AI 생성 코드 리뷰는 AI가 만든 변경이 요구사항에 맞고 유지보수할 수 있는지 사람이 검토하는 일이다.

## 개발할 때

변경된 줄과 주변 흐름을 읽고, 새 의존성이 필요한지, 실패 경로와 기존 동작은 유지되는지 확인한다. 실행했다고 보고한 테스트의 명령과 결과도 함께 본다.

## 기억할 점

다른 AI의 리뷰는 검토를 돕지만 승인 근거 전부가 될 수는 없다. 설명하기 어려운 큰 변경은 나눠 검토하고, 테스트를 삭제하거나 조건을 느슨하게 만들어 통과시킨 부분이 없는지도 확인한다.
