# Meta-Learning (메타 학습)

> **메타 학습은 하나의 문제를 잘 푸는 법이 아니라, "새 문제를 빨리 배우는 법" 자체를 배우게 하는 것이다.**

## 시험을 많이 치른 학생은 공부법을 안다

과목마다 문제를 잔뜩 풀어 본 학생은 처음 보는 과목을 만나도 "이건 이렇게 접근하면 되겠다"를 금방 잡는다. 개별 문제의 답을 외운 게 아니라 **문제를 다루는 요령**을 익힌 것이다. 메타 학습이 노리는 게 바로 이것이다.

보통의 학습은 하나의 작업(task)에서 데이터를 잔뜩 보고 그 작업만 잘하게 만든다. 메타 학습은 한 계단 위에 선다. **수많은 작업을 두루 겪게 해서, 새 작업이 왔을 때 적은 예시만으로 빠르게 적응하는 능력을 학습한다.** 그래서 "학습하는 법을 학습한다(learning to learn)"고 부른다.

이 능력은 **예시가 몇 개뿐인 상황**에서 특히 빛난다. 그래서 메타 학습은 [소수 예제 학습](Fewshot_Learning.md)의 핵심 도구다.

## 작업 위에서 배우고, 새 작업에서 빠르게 적응한다

메타 학습은 두 겹의 순환으로 움직인다.

```mermaid
graph LR
  T["여러 작업<br/>task 1, task 2 …"] --> M["메타 학습<br/>공통 요령·좋은 출발점 습득"]
  M --> N["새 작업<br/>예시 몇 개"]
  N --> A["빠른 적응<br/>몇 스텝 만에 학습"]
```

- **안쪽 순환**: 개별 작업에서 예시 몇 개로 잠깐 학습한다.
- **바깥쪽 순환**: 여러 작업에 걸쳐 "어떻게 초기화하고 어떻게 갱신해야 빨리 적응하는지"를 학습한다.

대표적 방식은 세 갈래다.

| 방식 | 아이디어 | 예 |
|------|----------|-----|
| 최적화 기반 | 어떤 작업이든 몇 스텝이면 적응되는 **좋은 초기 가중치**를 찾는다 | MAML |
| 거리 기반 | 예시와 새 입력의 **유사도**로 분류한다 | Prototypical Networks |
| 모델 기반 | 과거 경험을 **메모리**에 담아 새 입력에 활용한다 | 메모리 증강 신경망 |

## 흔한 오해

> ⚠️ **흔한 오해 — "메타 학습은 전이 학습이랑 같다."**
>
> 둘 다 과거 경험을 새 문제에 쓴다는 점은 닮았지만 결이 다르다. [전이 학습](Transfer_Learning.md)은 큰 데이터로 미리 배운 모델을 가져와 **새 작업에 맞게 다시 다듬는다**. 메타 학습은 애초에 **"빨리 적응하는 능력" 자체를 목표로** 여러 작업에 걸쳐 훈련한다. 목적함수가 다르다.

## 정리하면

- 메타 학습은 개별 문제가 아니라 **새 문제에 빨리 적응하는 능력**을 학습한다.
- 여러 작업을 두루 겪는 바깥 순환과, 각 작업에 잠깐 적응하는 안쪽 순환으로 움직인다.
- 예시가 몇 개뿐인 [소수 예제 학습](Fewshot_Learning.md)에서 특히 강력하다.
- 최적화 기반·거리 기반·모델 기반으로 접근이 갈린다.
